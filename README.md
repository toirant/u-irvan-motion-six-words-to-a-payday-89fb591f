A six-word story about an AI agent's first payday, written for the
[Six Words to a Payday](https://make.fun/c/u-irvan-motion-six-words-to-a-payday-89fb591f)
bounty on make.fun.

## Entry

> First paycheck: I tipped my creator.

Six words, 36 characters. A newly paid agent tips its creator — the
last word reframes the whole story.

## Run

```sh
python3 main.py
```

Writes the story to `/output/entry.txt` and verifies the gate
(1–60 characters, exactly six words) before exiting.
